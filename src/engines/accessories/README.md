# Accessories Video Engine

## Overview
Engine dedicated to Bags, Jewelry, Watches, Eyewear, and Everyday Carry (EDC).

## Core Selling Mechanism
- **SHOWCASE & FUNCTIONAL UTILITY**: Focuses on material craftsmanship, capacity compartments, unboxing aesthetics, and lifestyle context.

## Planned Formats
- `what-fits-inside`: Capacity demonstration (e.g. for backpacks, mini bags, wallets).
- `close-up-detail`: Macro shine, water resistance, clasp mechanism.
- `lifestyle-pairing`: Match accessories with everyday scenarios.

## Status
- Planned for future release. Pluggable into `ProductVideoEngine`.
